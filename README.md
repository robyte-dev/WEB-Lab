# Web II - React State Management & Auth Practice

A React application built with **Vite** and **Tailwind CSS** for practicing component state management, user authentication, user management, and contact card display.

##  Features

- **User Authentication & Management**: Interactive login, registration, and user management views.
- **Contact Cards**: Dynamic display of contact profile cards with props passing.
- **Modern UI**: Dark-themed dashboard built with Tailwind CSS.

##  Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4

##  Getting Started

### Prerequisites
Make sure you have Node.js installed on your machine.

### Installation

1. Clone or navigate to the project directory:
   ```bash
   cd my-app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application

Start the development server:
```bash
npm run dev
```

Open your browser and navigate to `http://localhost:5173` (or the URL shown in your terminal).

### Available Scripts

- `npm run dev` - Starts the development server with HMR.
- `npm run build` - Builds the project for production.
- `npm run preview` - Locally previews the production build.
- `npm run lint` - Runs Oxlint linter.
